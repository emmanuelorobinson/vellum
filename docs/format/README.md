# The .vellum format

Generated from `crates/vellum-types` by `scripts/gen-format.mjs`. Do not edit this file: run `pnpm format-spec:gen`.

## Document

A `.vellum` file.

| Property | Type | Required | Description |
|---|---|---|---|
| `components` | map from string to [Component](#component) | no | Components by id. |
| `fonts` | map from string to [FontFace](#fontface) | no | Custom fonts, keyed by the asset that holds each font file. |
| `imports` | map from string to string | no | The libraries this document uses: alias → relative path of a `*.lib.vellum` file. |
| `meta` | [DocumentMeta](#documentmeta) | yes | The format version, the name, what made the file and whether it is a library. |
| `pages` | array of [Page](#page) | yes | The pages, in order. |
| `styles` | map from string to [Style](#style) | no | Text and effect styles by id. |
| `themes` | map from string to array of string | no | Theme axes and their values. The first value of each axis is the default. |
| `variables` | map from string to [Variable](#variable) | no | Variables by id. |

## Definitions

### AliasEntry

An alias to another variable's value and the theme axis values it applies under.

| Property | Type | Required | Description |
|---|---|---|---|
| `$alias` | [VariableId](#variableid) | yes | The variable whose value this takes, by id. |
| `when` | map from string to string | no | Theme axis values this entry needs; empty means always. |

### Align

Alignment across a frame's main axis.

Type: one of "start", "center", "end"

### AssetId

An asset's id: the content hash of the file beside the document (`<name>.assets/`).

Type: string

### BlendMode

How a layer's colour combines with what is beneath it.

Type: one of "normal", "darken", "multiply", "color-burn", "linear-burn", "lighten", "screen", "color-dodge", "linear-dodge", "overlay", "soft-light", "hard-light", "difference", "exclusion", "hue", "saturation", "color", "luminosity"

### BoolOp

How a boolean node combines its children.

Type: one of "union", "subtract", "intersect", "exclude"

### Color

An sRGB colour with alpha. Printed as `#RRGGBB` when opaque and `#RRGGBBAA` otherwise, in upper
case; read in either case.

Type: string

### Component

A component, listed in the document's `components` by id.

| Property | Type | Required | Description |
|---|---|---|---|
| `name` | string | yes | The name shown in the components list. |
| `props` | map from string to [PropDef](#propdef) | no | The props an instance can set, by name. |
| `root` | [Node](#node) | yes | The default node tree; its root is the component's own frame. |
| `variants` | array of [Variant](#variant) | no | The variants. Each lists a value for every variant axis; the one whose values equal an instance's choice applies its overrides to the tree. |

### ComponentId

A component's id.

Type: string

### CornerRadius

Corner radius: one value for every corner, or four (top-left, top-right, bottom-right, bottom-left).

One of:

- [Value](#value). Every corner.
- array of [Value](#value). Top-left, top-right, bottom-right, bottom-left.

Type: one of "document", "library"

### NodeId

A node's id, unique within its document and never reused.

Type: string

### NodePatch

Property values to set on one node: a JSON object whose keys are node properties (`fills`, `visible`,
`content` and so on). Every key must be a property some node has, and a patch cannot set the node's id
or its children (a children override does that). The values are checked when the patch is applied to a
node, because only then is its kind known: the result must read back as that node.

Type: object

### Override

What an instance does to one node inside its component's tree. Written as a single key: `props`,
`replace` or `children`.

- `props`: [NodePatch](#nodepatch). Sets properties of the node. It keeps its id, its type and its children.
- `replace`: [Node](#node). Replaces the node with this one. Boxed because a node is much larger than the other two.
- `children`: array of [Node](#node). Replaces the node's children with these.

### Padding

Padding: one value for all sides, two (vertical, then horizontal, as in CSS) or four (top, right,
bottom, left).

One of:

- [Value](#value). All four sides.
- array of [Value](#value). Vertical, horizontal.
- array of [Value](#value). Top, right, bottom, left.

`{"hug": 40}` or `{"fill": 40}`.

### VarRef

A reference to a variable, written `{"$var": "<variable id>"}`.

It names the variable by its id, as every other reference in the file does (`componentId`, `asset`,
`textStyle`). A rename changes the variable's name and nothing else, and two branches that rename and
use a variable merge without leaving a dangling name. The name is for people and tools, and it lives in
the variable's own entry (see `Variable`).

| Property | Type | Required | Description |
|---|---|---|---|
| `$var` | [VariableId](#variableid) | yes | A variable's id. |

### Variable
