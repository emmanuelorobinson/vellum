These pages are for people who change {{brand}}. They describe the workspace, the commands, the checks that a change must pass, and the rules
that protect the product's design, its licence and its clean-room status.

## Start here

1. [Workspace](/docs/development/workspace): where each part of the repository lives, and which files are read-only
2. [Commands](/docs/development/commands): the commands for building, testing and checking the workspace
3. [Verification](/docs/development/verification): the gates a change must pass, and the lanes that need extra tools
4. [Contributing](/docs/development/contributing): how a change is made, reviewed and recorded

## Rules

- [Clean room and licensing](/docs/development/clean-room-and-licensing): what the project may copy, port and link
- [Version policy](/docs/development/version-policy): how versions are pinned and recorded
- [Design source](/docs/development/design-source): how the design file is read, and how tokens are generated from it
